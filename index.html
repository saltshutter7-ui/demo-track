SIR - Site Inspection Report (linked Google Sheet)

How to link: 1) Open the Google Sheet where the SIR form saves its answers. 2) File > Share > Publish to web > choose the sheet tab and Comma-separated values (.csv) > Publish. 3) Paste that link below (or the normal sheet link, if the sheet is shared as "Anyone with the link - Viewer"). 4) Write the exact heading of the column that holds the INDENT NO (PR number). 5) Press Test, then Save.
Rule: if a PR number of 100 KVA & above is found in that column, its SIR is done, otherwise it is pending. The result is shown in the Summary screen under "SIR Summary". Only the PR number column is read.
