Download TF-Tracker

Use the app in its own window, without opening the browser. Choose your device.

Windows computer or laptop

TF-Tracker.exe · no installation, no admin password.

Download for Windows (.exe)
  1. Download the file and double-click it.
  2. If Windows says "Windows protected your PC": click More info, then Run anyway. This comes only once, because the app is not paid-signed.
  3. The first time it asks for the workshop code from your Admin.

Android phone

TF-Tracker.apk

Download for Android (.apk)
  1. Download and open the file.
  2. If the phone asks, allow Install unknown apps for your browser. If Play Protect warns, choose Install anyway.
  3. Excel files open in the Share sheet: save to Files or send on WhatsApp. Printing is not available in the app.

iPhone / iPad (and any phone without the app)

There is no app file for iPhone. Add the site to the home screen instead; it opens like an app.

  1. iPhone: open the site in Safari → Share button → Add to Home Screen.
  2. Android (Chrome): menu → Install app (or Add to Home screen). This works instead of the .apk.
  3. Computer (Edge / Chrome): the Install icon in the address bar. This works instead of the .exe.

New to this? On the login page tap "First time on this phone or computer? Enter your workshop code" and type the code given by your Admin. The app always shows the newest version of the site, so you do not need to download it again after an update.
The download buttons work after the Admin has built the apps once (GitHub > Actions > Build apps).
